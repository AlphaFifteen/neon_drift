# neon_drift
It's a fast paced cyberpunk endless runner where you pilot a high speed hover skiff down a neon grid, dodging razor sharp barriers and collecting pulsing nodes to build your multiplier

It uses raw HTML5 Canvas, no external libraries, frameworks, and heavy tinyfication tricks to sit comfortably under 4 KB uncompressed (around 1.2 KB when gzipped). featuring crisp vector style glowing shaders, dynamic particle explosions, screen shake, and an authentic retro arcade feel.
